## Repris

- Barre de progression à trois zones : possédé / manquant / à paraître
- Anatomie d'une ligne de collection : couverture, titre, sous-titre, `X / Y`, barre
- Marqueur « à paraître » de largeur fixe, pas proportionnel

## Écarté

- La liste verticale de couvertures sur la page Édition, remplacée par la grille de pastilles
- La page de détail d'un tome, hors périmètre V1
- Les compteurs sociaux, les prix marchands, les boutons d'achat
- La palette rouge sur noir

## Convention

Nommer les fichiers d'après l'écran qu'ils illustrent (`collection-liste.png`,
`edition-pastilles.html`), jamais d'identifiant généré.

Compresser les images avant de committer : Git conserve chaque version d'un binaire
indéfiniment dans l'historique.
